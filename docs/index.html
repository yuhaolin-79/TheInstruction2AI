MNIST 数据集探索

MNIST 是深度学习领域的 "Hello World" 数据集，包含 0–9 共 10 类 手写数字的灰度图像，每张 28×28 像素。

模型架构

我们构建了一个轻量级的卷积神经网络，核心思路：卷积提取特征 → 池化降维 → 全连接分类。

网络结构

输入 (1 × 28 × 28) │ Conv2d 1→16, 3×3, padding=1 → 16×28×28 │ ReLU + MaxPool(2×2) → 16×14×14 │ Conv2d 16→32, 3×3, padding=1 → 32×14×14 │ ReLU + MaxPool(2×2) → 32×7×7 │ Flatten (32 × 7 × 7 = 1,568) │ Linear 1,568 → 128 + ReLU + Dropout(0.25) │ Linear 128 → 10 │ Softmax → 0–9 各类别概率

各层参数

层输入 → 输出参数量作用
Conv1 + ReLU + MaxPool1×28×28 → 16×14×14160提取低级特征（边缘、线段）
Conv2 + ReLU + MaxPool16×14×14 → 32×7×74,640提取高级特征（笔画组合）
Dropout(0.25)—0防止过拟合
FC1 + ReLU1,568 → 128200,832特征映射到隐层
Dropout(0.25)—0再次防止过拟合
FC2128 → 101,290输出 10 类分数
总参数量：约 63k — 轻量级模型，CPU 上即可快速训练和推理。

训练过程

超参数配置

超参数值说明

Epochs5完整遍历训练集 5 次
Learning Rate0.001Adam 优化器的学习率
Loss 函数CrossEntropyLoss多分类交叉熵损失

Dropout0.2525% 概率随机丢弃神经元

数据增强

训练时对图片进行随机增强，等效于获得更多样化的训练数据，提升模型泛化能力：

  • 随机旋转：±10°
  • 随机平移：±10%
  • 随机缩放：±10%
  • 随机剪切：±5°
训练耗时： CPU 约 3–5 分钟，Apple Silicon / NVIDIA GPU 约 1–2 分钟。

为什么准确率能到 99%？

  • MNIST 比较简单：28×28 灰度图，10 个类别，笔画清晰
  • 数据增强：随机旋转、平移、缩放让模型见过更多变化
  • Dropout 防过拟合：训练时随机丢弃神经元，增强泛化能力
